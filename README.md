# Food Court Ordering System

## Description

This web application is designed specifically for food courts to enhance the customer experience.
It allows customers to sit at any table within the food court and order from all available restaurants from their phone.
With a simple QR code scan at the table, customers can browse menus, place orders across multiple restaurants, and pay directly within the application, eliminating the need to wait at different counters.

## Key Features

- **Centralized Ordering**: Order from any restaurant in the food court from a single interface.
- **Table-Side QR Access**: Scan a QR code at your table to start ordering immediately.
- **Integrated Payments**: Securely pay for your orders directly on your phone.
- **Administrative Portal**: Tools for restaurant owners to manage menus and settings.

## Tech Stack

- **UI Components**: [Radix UI](https://www.radix-ui.com/), [Shadcn UI](https://ui.shadcn.com/), [Lucide React](https://lucide.dev/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/), [Zod](https://zod.dev/)
